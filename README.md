# AirBnB-Data-Visualization

## Overview

This project analyzes Airbnb listing data using Excel and Tableau, focusing on pricing patterns, bedroom distribution, and geographical trends across different zipcodes.

## Tools Used

- Microsoft Excel for data management and cleaning
- Tableau for interactive visualizations and mapping

## Dataset

The Excel dataset includes detailed Airbnb listing information:
- Property details (bedrooms, bed type, amenities)
- Pricing information (daily, weekly, monthly rates)
- Location data (zipcodes)
- Additional fees and policies

## Visualizations in Tableau

1. Average Price by Bedrooms
   - Bar chart showing price progression from 1-6 bedrooms
   - Clear price scaling from $96.2 for 1 bedroom to $584.8 for 6 bedrooms

2. Listings Distribution
   - Distribution analysis showing 1,811 one-bedroom properties
   - Decreasing frequency pattern for larger properties

3. Geographical Analysis
   - Interactive map showing price variations by zipcode
   - Bar chart of average prices across different zipcodes

4. Revenue Trends
   - Line graph showing revenue progression throughout 2016

## Key Insights

- One-bedroom properties dominate the market
- Clear price progression with increasing bedroom count
- Significant price variations across different zipcodes
- Detailed revenue tracking across weeks in 2016
